# openGym فارسی

نسخهٔ فارسی برنامهٔ ثبت تمرین و پیگیری وزن بدن، بر پایهٔ [alexpcosta/opengym](https://github.com/alexpcosta/opengym).

## تغییرات آماده‌شده

- ترجمهٔ تمام ۷۸۱ کلید رابط موجود و متن‌های اضافی مدیریت، دسترس‌پذیری و نسخهٔ نمایشی.
- فارسی به‌عنوان زبان پیش‌فرض پروفایل‌های جدید؛ زبان پروفایل‌های قبلی حفظ می‌شود.
- چیدمان راست‌به‌چپ، اصلاح جهت فلش‌ها، جست‌وجو، کلیدهای روشن/خاموش و کنترل‌های چندگزینه‌ای.
- فونت وزیرمتن همراه برنامه، بدون وابستگی به سرویس فونت خارجی. مجوز فونت در `frontend/src/assets/fonts/Vazirmatn-LICENSE.txt` است.
- پذیرش عددهای فارسی و عربی در ورودی وزنه و تکرار؛ ذخیرهٔ داده‌ها همچنان عددی است.
- تاریخ و عدد با قالب فارسی؛ تقویم و زمان‌بندی فعلاً میلادی هستند و به شمسی تبدیل نشده‌اند.
- ترجمهٔ اعلان‌های سرور بر اساس زبان پروفایل، و خروجی چاپی راست‌به‌چپ.
- مربی هوش مصنوعی زبان پروفایل را دریافت می‌کند؛ برای زبان فارسی، همهٔ نام‌ها و توضیحات قابل نمایش باید فارسی تولید شوند.
- نام فارسی هر ۱۳۲۴ حرکت، همراه جست‌وجوی فارسی و انگلیسی؛ شناسه‌ها و نام‌های اصلی برای سازگاری ورود سابقه حفظ می‌شوند.
- واحدهای فارسی، خلاصهٔ ست‌های هوازی، زمان‌ها و پیام‌های خطای قابل نمایش.
- صفحات معرفی، راهنما و دربارهٔ سایت با محتوای فارسی، چیدمان راست‌چین و قلم محلی.

## موارد باقی‌مانده برای فارسی‌سازی کامل

نام هر ۱۳۲۴ حرکت فارسی است. راهنمای اجرای ۳۳ حرکت، شامل همهٔ ۱۷ حرکت برنامهٔ شروع، ترجمه و با متن اصلی تطبیق داده شده است. راهنمای ۱۲۹۱ حرکت دیگر هنوز با برچسب انگلیسی نمایش داده می‌شود.

خروجی مدل اولیهٔ ترجمه در بعضی وضعیت‌ها و اصطلاحات ورزشی معنی را تغییر می‌داد و وارد برنامه نشده است. تکمیل فارسی‌سازی راهنماها به ترجمه و بازبینی بقیهٔ حرکت‌ها نیاز دارد. نقشهٔ نام‌ها در `frontend/src/exercise-names/fa.js` و راهنماهای بررسی‌شده در `frontend/src/instr/fa.js` قرار دارند. تعداد و ترتیب مراحل هر حرکت باید با مجموعه‌دادهٔ اصلی یکسان بماند. متن‌های نوشته‌شده توسط کاربر و شناسه‌ها خودکار ترجمه یا تغییر نمی‌کنند.

## محل کد و دسترسی از مرورگر

مخزن نسخهٔ فارسی: [Igen3ral/Gym](https://github.com/Igen3ral/Gym).

برای نسخهٔ تعاملی بدون سرور، گردش‌کار `Deploy demo to GitHub Pages` از قبل در مخزن وجود دارد. پس از ورود تغییرات فارسی به شاخهٔ `main`:

1. در تنظیمات مخزن، بخش **Pages**، منبع انتشار را **GitHub Actions** قرار دهید.
2. اگر گردش‌کارهای فورک غیرفعال هستند، آن‌ها را در بخش **Actions** فعال کنید.
3. گردش‌کار **Deploy demo to GitHub Pages** را روی `main` اجرا کنید.
4. پس از موفقیت انتشار، نشانی سایت را از خروجی همان گردش‌کار باز کنید.

این نسخه در مرورگر کار می‌کند و داده‌ها در همان مرورگر ذخیره می‌شوند. ورود با کلید ورود، همگام‌سازی بین دستگاه‌ها و مربی زنده به سرور نیاز دارند؛ برای آن‌ها روش اجرای محلی یا Docker زیر را استفاده کنید. تا موفقیت گردش‌کار، هیچ نشانی سایت را منتشرشده فرض نکنید.

## اجرای محلی

پیش‌نیاز: Node.js 24 و npm. در همان checkout موجود کار کنید؛ ساخت worktree لازم نیست.

```bash
cd api
npm ci
cd ../frontend
npm ci
cd ..
bash scripts/fetch-media.sh
```

در سه پایانهٔ جداگانه:

```bash
# از ریشهٔ مخزن؛ داده‌های محلی در مسیر ignored نگهداری می‌شوند.
cd api
PORT=3000 ORIGIN=http://localhost:5173 DATA_DIR=../data npm start
```

```bash
# از ریشهٔ مخزن؛ تصاویر و انیمیشن‌های محلی
python3 -m http.server 8888 --bind 127.0.0.1 --directory media
```

```bash
# از ریشهٔ مخزن
cd frontend
npm run dev -- --host 127.0.0.1 --port 5173
```

حالت مهمان بدون حساب یا اعتبارنامه قابل استفاده است. ورود با کلید ورود و مربی زنده به تنظیمات سرور و حساب مربوط به خود نیاز دارند؛ راهنمای اصلی مخزن را ببینید. هیچ توکن یا کلید خصوصی را در کد قرار ندهید.

## بررسی تغییرات

```bash
cd frontend
npm test
node scripts/check-locales.mjs
npm run build
cd ../api
npm test
```

آزمون‌های فارسی، تطابق کلیدها و جای‌نگهدارها، تغییر جهت زبان، ورودی عدد فارسی، خروجی چاپی و اعلان‌ها را بررسی می‌کنند.

## استقرار با Docker

از ریشهٔ مخزن و پس از تنظیم `.env` طبق مستندات اصلی، `docker compose up --build -d` را اجرا کنید. گزینهٔ `--build` لازم است تا تصویرهای آمادهٔ بالادستی جای نسخهٔ اصلاح‌شدهٔ شما اجرا نشوند. ساخت Docker در محیط توسعه امتحان شد، اما دسترسی شبکه به مخزن بسته‌های آلپاین مانع تکمیل آن شد؛ اجرای کانتینر هنوز تأیید نشده است.

مجوز اصلی AGPL-3.0-or-later و اطلاعات انتساب کتابخانهٔ حرکات و فونت حفظ شده‌اند.
